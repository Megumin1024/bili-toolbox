# 监控模块约定

## 组成

- `tools/monitor/page.py`：桌面端参数、启动和浏览器打开方式。
- `tools/monitor/server.py`：现有 HTTP 服务和数据响应。
- `tools/monitor/static/index.html`：浏览器仪表盘的布局、图表和状态展示。

## 修改规则

- 新指标必须同时检查服务端字段、静态页面读取逻辑和错误处理。
- 不单独修改前端字段名，也不在前端猜测服务端未提供的数据。
- 保持连接中、正常、错误、暂无数据和图表加载失败状态。
- 保持现有系统浏览器打开方式和历史数据结构。
- 仪表盘静态资源必须继续由 `build_toolbox.spec` 打包。

## 验证尺寸

至少检查 1440px、980px 和 768px 宽度，确认没有横向溢出、图表遮挡或状态徽章被裁切。
