# 界面层约定

## 页面组成

标准任务页保持以下顺序：

```text
页面标题 → 参数 → 操作/进度 → 结果 → 日志
```

优先继承 `app/task_page.py`，复用 `app/widgets.py` 中的 `PageHeader`、`StatusPill`、`ProgressBlock`、`ResultCard`、`LogPanel`、`PathRow` 和 `card()`。不要在单个页面复制一套任务控制、日志或结果卡片。

## 主题与文字

- 深色/浅色令牌集中在 `app/theme.py`。
- 新控件优先使用对象名和现有主题规则，不在页面中散落颜色。
- 用户可见文案默认使用简体中文。
- 仅保留必要技术名称，例如 Excel、gRPC、TLS、BV、URL。
- 装饰元素保持克制，不引入角色素材、持续动画或与功能无关的装饰堆叠。

## 响应式检查

界面改动至少检查：

- 960×640；
- 1440×900；
- Windows 125% 和 150% 缩放；
- 四个页面导航和深浅主题即时切换；
- 设置保存后重启恢复；
- 待开始、运行中、取消、成功、失败和结果链接状态。

使用 `scripts/take_screenshots.py` 生成截图，重点观察裁切、重叠、文字对比度、日志区域和页面底部留白。
