# 任务流水线约定

## 页面与流水线分工

- `page.py` 负责控件、参数收集、输入校验和显示状态。
- `pipeline.py` 负责任务编排、数据处理、进度报告和取消响应。
- `core.py` 只在需要把较大的数据处理或导出逻辑从流水线拆出时使用。
- 页面通过 `TaskRunner` 的现有信号与流水线通信，不直接复制线程管理逻辑。

## 不变量

未经明确要求，不改变：

- 开始/取消按钮行为；
- 进度和日志信号；
- 断点续传和中断后恢复；
- JSONL/XLSX 字段和文件命名；
- 自动打开 Excel 或浏览器的现有行为；
- 公开数据范围、请求频率、代理、指纹和风控策略。

## 新功能流程

1. 为功能建立单独目录，不从另一个工具复制并继续分叉实现。
2. 先定义参数和输出契约，再连接页面和流水线。
3. 运行待开始、运行中、取消、成功、失败五类状态检查。
4. 对配置新增字段提供旧配置可用的默认值。
5. 如果需要修改 `core/` 或公共任务协议，先记录影响范围，再运行三个工具的回归验证。
